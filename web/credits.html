The browser runs the same C Game Boy core as the hardware candidates. It does not emulate the JieLi chip, board timing or electronics. Sound is synthesized at frame granularity. Some games may have timing, visual or audio inaccuracies.

GB only; no GBC-only games, GBA, link cable, rumble or save states. Dual-mode cartridges run in monochrome. Browser cartridge RAM saves locally, keyed by cartridge SHA-256; real-time-clock state does not persist while closed. Hardware cartridge RAM is temporary. The FM-1 trial retains USB updating; the SMK37 candidate has no updater and is not installable. Hardware gameplay and recovery still require testing.

The included diagnostic cartridge is an original test program. No commercial game ROMs or Nintendo boot ROM are bundled.
